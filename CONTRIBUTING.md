# Contributing to Shift

Thank you for taking the time to contribute to Shift!

## How to Report Bugs
- Check existing GitHub Issues to ensure the bug hasn't been reported.
- Open a new issue with steps to reproduce the bug and your `.shift` source code.

## Pull Requests
1. Fork the repository.
2. Create a new feature branch (`git checkout -b feature/new-syntax`).
3. Ensure `compiler/shiftc.py` successfully parses tests in `examples/`.
4. Submit a Pull Request targeting the `main` branch.
